# VANTAGE - Modern Agency Landing Page
A clean, responsive, and modern landing page for **VANTAGE**, a digital solutions agency. Built with pure **HTML5** and **CSS3**, this project showcases a structured layout featuring custom responsive navigation, service cards, contact integration, and modern design principles.
## ✨ Features

- **Responsive Navigation**: Built-in CSS-only toggle sidebar menu for mobile and tablet views.
- **Hero Section**: High-impact heading, value proposition, call-to-action button, and showcase imagery.
- **Services Section**: Card-based layout highlighting UI/UX Design, Web/Mobile Development, and Digital Marketing.
- **Contact Section**: Split layout displaying office details alongside an interactive contact form.
- **Semantic Markup**: Formatted using semantic HTML elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- **Clean Styling**: Modular CSS architecture separating layout and aesthetics.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic document structure and accessible form controls.
- **CSS3**: Custom styling, layout positioning, media responsiveness, and menu interactions.
